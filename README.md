# 冀中 / 冉庄地道战资料板

游戏设计研究用书目站：整理冀中平原 / 保定清苑冉庄地道战相关公开网页、馆藏书目与实地信息。优先采有难度的过程、规则与空间尺度，不是气氛口号。

在线入口：仓库开启 GitHub Pages 后，一般为 `https://<用户名>.github.io/didaozhan-sources/`。

## 开启 GitHub Pages

1. 将本仓库推到 GitHub（建议公开仓库 `didaozhan-sources`）
2. 打开 **Settings → Pages**
3. **Source** 选 **Deploy from a branch**
4. Branch 选 **main**，文件夹选 **/ (root)**
5. 保存后等待一两分钟，按提示打开站点地址

## 本地预览

在本目录打开 `index.html` 即可（双击或用本地静态服务）：

```bash
# 任选其一
python3 -m http.server 8080
# 然后浏览器打开 http://127.0.0.1:8080/
```

无构建步骤，无 CDN 依赖。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 站点首页 |
| `styles.css` | 样式（含浅色/深色系统偏好） |
| `CONTENT.md` | 与页面同步的 Markdown 书目正文，便于后续改稿 |

## 注意

- 勿把盗版全文站当一手来源；手册类条目以馆藏/购书为准。
- 口述与烈属材料涉及创伤：引用脱敏、注明出处；对外展示需征得同意。
