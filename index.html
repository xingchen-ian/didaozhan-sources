冀中 / 冉庄地道战资料板

本站为「抗日战争时期地道战」游戏设计搜集资料用：主案例落在冀中平原 / 保定清苑冉庄。材料按「玩法能用」分八类。电影与展览可当大众记忆对照，设计时尽量回手册、口述与遗址尺度核对。访问方式标为：公开网页 / 需馆藏或购书 / 需实地。

游戏设计研究用书目。优先采有难度的过程、规则与空间尺度，不是气氛口号或风景贴图。本站条目以可核对的公开网页、馆藏书目与实地信息为主；不把盗版全文站当一手来源。

五个过程（设计时先盯这些）

  1. 挖与改洞 — 单口「蛤蟆蹲」→双口→多口→干支线网；工具、出土、人力、灯油开支
  2. 进洞与封锁 — 烟、水、火、毒、掘口；卡口、翻板、翻眼、防毒/防水口
  3. 洞内生活与联络 — 吃、便、休息室；铃绳、土电话、递步哨、指路牌
  4. 地面—地下火力转换 — 枪眼、高房/地堡、假堡「堆土借弹」、地雷引线入洞
  5. 情报与协作 — 联村通道、情报接力、妇孺掩护、民兵分工与全村动员

建议阅读顺序

  1. 杨成武《冀中平原上的地道斗争》相关报道与书目线索（构筑、五防、洞内生活）
  2. 冉庄布局与形势图描述（干线/支线/工事类型与尺度）
  3. 李恒彪等口述时间线（一次具体行动：警报→进洞→判断→开火/转移）
  4. 遗址/纪念馆实地（身体尺度与伪装洞口）
  5. 档案汇编与学术综述（校正电影夸张、摆清系统边界）
  6. 电影《地道战》与展览图录（当记忆文本，不当真相源）
  7. 敌方/对抗视角材料（对方怎么找洞、怎么熏、怎么逼民）

表述与伦理（简短）

  • 采的是过程与阻力，不是民俗符号堆砌或口号墙。
  • 口述与烈属讲述涉及创伤与牺牲：引用时脱敏、注明出处；对外展示需征得同意。
  • 数字（地道长度、作战次数、歼敌数）在公开报道中常有出入，设计侧当「系统量级」用，并注明来源年份。
  • 游客可走的地道多经加高加固；游戏尺度应对照当年约高 1–1.5 m、宽 0.7–0.8 m 的记载，不要按旅游通道做。
  • 涉及日军暴行与毒气等史实须有出处；对抗设计不要娱乐化屠杀。

1.作战与构筑手册

《冀中平原上的地道斗争》 需馆藏或购书

  • 作者 / 机构：杨成武（时任冀中军区司令员）；1945 年由冀中军区司令部以「绝对秘密」油印下发
  • 年份：1945（油印本）；1987（辽宁大学出版社正式出版，ISBN 7561001789，约 133 页）
  • 用途：构筑要求、战术技术、防火/水/烟/毒、洞内吃住便与联络——最接近「规则书」的一手总结
  • 访问：需馆藏或购书（全文不宜声称可免费下载）
  • 公开网页（档案与内容介绍，非全书）： 地道里的「神兵」生活（人民网 / 河北日报，2016）

《冀中平原上的民兵斗争》 需馆藏或购书

  • 作者 / 机构：程子华主持撰写
  • 年份：1942；1944 年 6 月八路军总政治部整理发表并加按语
  • 用途：民兵组织与地道战推广背景；纠正「挖洞=逃跑」的认识
  • 访问：需馆藏或购书；介绍性公开网页：
    • 程子华推动冀中地道战（人民网党史频道，2018）
    • 地道战战术家程子华（中国新闻网，2015）

《地道战档案史料选编》 需馆藏或购书

  • 作者 / 机构：河北省档案馆编；河北人民出版社
  • 年份：1987；ISBN 7202000261；约 304 页
  • 用途：集中收录冀中地道相关指示、报告与杨成武文等档案选编
  • 访问：需馆藏或购书（勿用盗版 PDF 站当来源）
